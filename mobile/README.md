# Alpha Mobile ERP - Mobile Technician App (React Native & Expo)

A native mobile client built specifically for field technicians, repair specialists, and warehouse stock counters.

---

## Features
- **My Assigned Tickets**: Live view of open repair tickets with immediate status updates (`DIAGNOSED`, `IN_PROGRESS`, `READY_FOR_PICKUP`).
- **Camera & Barcode Scanner**: Instant camera scanning of spare parts barcodes, phone serials/IMEIs, and device condition photo evidence.
- **Offline-First Sync**: Local storage caching with queued synchronization when network connection is restored.
- **Push Notifications**: Real-time push notifications when new urgent tickets are assigned.

---

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start Expo Development Server
npm start

# 3. Run on Android Device / Emulator:
npm run android

# 4. Run on iOS Simulator:
npm run ios
```
